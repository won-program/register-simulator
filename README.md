# レジバイトシミュレーター 🧾

架空のお店「まちかどマート」で、3分間のレジバイト。おつりを速く正確に返して、自己ベストを目指すブラウザゲームです。

**HTML / CSS / JavaScriptのみ。サーバー、npm、ビルド、ログイン、APIキーは必要ありません。外部通信・外部フォント・外部音源も使いません。**

## すぐ遊ぶ

このフォルダーの **`index.html` をブラウザで開く**だけで起動します。ファイルを個別に移動せず、フォルダー構成を維持してください。

1. 「出勤する」を押します。
2. お買上げ合計と、確定したお預かり金額を確認します。
3. **お預かり − 合計**を入力し、Enter または「お会計を確定」を押します。
4. 自動で次のお客様に進みます。3分経つと勤務終了です。

スマホは入力欄をタップすると数字キーボードを使えます。全角数字にも対応。0円のおつりは `0` を入力してください。初めの30秒は簡単なお会計です。

追加小銭・レジ袋の演出中は入力できません。金額確定後から回答時間を計測します。小銭大量客は表示された硬貨の合計を自分で求め、**最後のおつりだけ**を入力します。すべての商品価格は税込です。

## 主な機能

- 180秒の勤務、32種類の商品、段階的な難易度上昇
- 連続正解COMBO、速度ボーナス、お急ぎボーナス、ラッシュ
- 表情が変わるお客様、速く対応すると減る待ち行列
- 勤務結果カード、4段階のランク、結果テキストのコピー
- 自己ベスト、7種類の実績、直近20回の勤務履歴
- localStorageによる保存、確認付きの記録削除
- Web Audioによる効果音と音ON/OFF（初期はOFF）
- PC・タブレット・スマホ、320px幅、タップ・Enter操作対応
- キーボードフォーカス、読み上げ用ラベル、動きを減らすOS設定に対応

待ち人数は最大12人。行列と機嫌による減点・ゲームオーバーはありません。ラッシュは勤務開始60〜85秒、125〜155秒に発生し、来客が増え、商品数が少し多くなります。

別タブに移っても時計は進み、戻ったときに期限を確認します。ページを閉じたり再読み込みすると途中の勤務は終了し、未完了の勤務は保存しません。「勤務を中断」の確認中も時計は進みます。

## 特殊客

| お客様 | 内容 |
| --- | --- |
| 追加の小銭 | 1.1秒の演出後、お預かりに小銭を加算して確定 |
| レジ袋を追加 | 1.1秒の演出後、レジ袋5円を合計に加算して確定 |
| 高額紙幣 | 5,000円または10,000円でお支払い |
| まとめ買い | 商品5〜6点。合計は表示されます |
| 小銭でお支払い | 硬貨の額面と枚数から預かり金額を計算 |
| お急ぎのお客様 | 表情の変化が速く、5秒以内の正解で+25pt |

## 採点

正解ポイントは次の合計です。

- 基本：**100pt**
- 速度：`max(0, round(50 − 回答秒数 × 5))`（0〜50pt）
- COMBO：`min(50, (今回のCOMBO − 1) × 5)`（0〜50pt）
- お急ぎ客：5秒以内の正解で25pt
- 回答時にラッシュ中なら、合計を**1.2倍**して四捨五入

不正解は **−100pt**、スコアの下限は0pt。COMBOは0に戻ります。3秒以内の正解が「PERFECT!」、6秒以内が「FAST!」。正解後は約0.54秒、不正解後は正解確認のため約1.45秒で次の客に進みます。

レジ差額は `正しいおつり − 入力したおつり` の累計。多く返すとマイナス、少なく返すとプラスです。未回答の客は接客人数・正答率・差額に含みません。平均時間は全回答、最速時間は正解だけが対象です。

結果の「獲得ポイント」は `最終スコア ÷ 100` の小数点以下を切り捨てた累計用の記念ポイントです。買い物や有料機能はありません。

| ランク | 条件 |
| --- | --- |
| レジマスター | 接客30人以上・正答率95%以上・平均回答5秒以内 |
| レジの達人 | 接客20人以上・正答率90%以上 |
| 頼れるレジスタッフ | 接客10人以上・正答率75%以上 |
| 新人アルバイト | 上記以外 |

差額0円の実績・回数とノーミス実績は、1人以上の接客が必要です。差額0円は誤答が相殺された場合も対象ですが、ノーミス実績は全問正解の勤務だけです。

## 保存される記録

ブラウザの `localStorage` の `machikado-register-v1` に保存します。

- ハイスコア、最高接客人数、最大COMBO、最高正答率、最速正解
- 完了した勤務回数、差額0円達成回数、累計高速正解数、累計ポイント
- 解除済み実績、直近20回の結果、音ON/OFF

記録は端末・ブラウザ・公開先ごとです。ログイン・同期・オンラインランキングはありません。ブラウザのサイトデータ削除で消えます。プライベートモードでは終了時に消える場合があります。ファイルを直接開いた場合の保存はブラウザに依存するため、継続して遊ぶときはGitHub Pagesの同じURLを使ってください。保存できない環境では通知し、ゲーム自体は続けられます。

## ファイル構成

```text
index.html            すべての画面とダイアログ
styles.css            デザイン、レスポンシブ、アニメーション
assets/
  favicon.svg         お店のアイコン
js/
  core.js             商品・特殊客生成、ゲーム状態、採点、タイマー判定
  storage.js          記録検証、保存・読込・削除、実績解除
  audio.js            Web Audioの効果音
  app.js              操作受付、画面更新、結果共有
README.md             この説明書
TESTING.md            動作確認の範囲・結果
tests/
  verify.py           開発用ブラウザ自動テスト（公開には不要）
.nojekyll             GitHub Pages用
.gitignore            開発用ファイルをアップロードから除外
```

ゲーム内のイラストはHTML/CSS、商品と実績アイコンは絵文字です。画像のダウンロードは不要で、絵文字の見た目は端末によって異なります。ユーザー入力や保存データは `textContent` / `value` で扱い、HTMLとして挿入しません。

## GitHub Pagesで公開する

1. GitHubで新しい **Public** リポジトリを作成します。
2. このフォルダーの中身をアップロードします。`index.html` がリポジトリの一番上に来るようにしてください。
3. リポジトリの **Settings → Pages** を開きます。
4. 公開元で **Deploy from a branch** を選びます。
5. ブランチを **main**、フォルダーを **/ (root)** にして保存します。
6. 公開処理後に表示されるURLを開きます。そのURLを友達に送れば遊べます。

公開に必須なのは **`index.html`、`styles.css`、`js`フォルダー全体、`assets`フォルダー全体**です。`README.md` と `.nojekyll` も一緒に置いてください。`tests` と `TESTING.md` は任意です。

**`.tools` と `.test-artifacts` は開発専用なのでアップロード不要です。** Gitを使う場合は `.gitignore` で除外されますが、GitHubの画面へドラッグする場合は自分で除外してください。外側のフォルダーを丸ごと入れるのではなく、その中身をアップロードします。

パスはすべて `./` から始まる相対参照のため、`https://ユーザー名.github.io/リポジトリ名/` のようなURLで動きます。ファイル名の大文字・小文字やフォルダー構成は変更しないでください。更新が見えないときは、公開処理完了を待ってから再読み込みします。

## 開発用の確認（遊ぶだけなら不要）

PythonとPlaywrightがある場合、`python tests/verify.py` で自動チェックできます。Windowsではインストール済みChromeを使い、それ以外ではPlaywrightのChromiumを使います。必要なら環境変数 `BROWSER_PATH` でブラウザ実行ファイルを指定してください。

```text
python -m pip install playwright
python -m playwright install chromium
python tests/verify.py
```

テスト用サーバー・加速時計・特殊客固定はテストプロセス内だけで使用します。公開ゲームにはテスト専用URLや隠しチートを設けていません。サーバーやPythonは公開・プレイには不要です。
